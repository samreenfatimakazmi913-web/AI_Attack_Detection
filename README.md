
# AI Attack Detection

## Project Description
This project uses machine learning to detect malicious network traffic and identify cyber attacks.

## Datasets
- UNSW-NB15
- CICIDS2018

## Feature Selection
- 43 Old Features
- 10 Additional Temporal Features
- 53 Total Features

## Data Preprocessing
- Data Cleaning
- Missing Values Inspection
- Label Verification
- Feature Selection
- Training and Testing Split
- Median Imputation

## Machine Learning Models
- Random Forest
- XGBoost
- Neural Network

## Project Goal
To evaluate machine learning models for network attack detection and compare the performance of 43 old features with 53 features including additional temporal features.
